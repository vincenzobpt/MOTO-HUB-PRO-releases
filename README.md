# MOTO-HUB Pro — Releases

Pre-built APK downloads for **MOTO-HUB Pro**, the closed-source companion app to
[MOTO-HUB](https://github.com/vincenzobpt/MOTO-HUB) (Core).

**This repository contains no source code.** MOTO-HUB Pro's source is closed and
private. Only signed release APKs are published here, under the
[Releases](../../releases) tab.

## What is MOTO-HUB Pro?

MOTO-HUB Pro provides the full MOTO-HUB feature set (Mirroring, Android Auto, Ride
Dashboard, Trips, Navigation...) with no GPL-3.0/AGPL-3.0 code of its own. It reaches
Core's T-Box transport and Android Auto receiver exclusively through a Binder IPC
bridge exposed by the Core app.

**MOTO-HUB Core must be installed and running for Pro to work.** Install Core first,
pair it with your T-Box, then install Pro from the release matching your device.

## Installation

1. Download the latest APK from [Releases](../../releases).
2. Enable "Install unknown apps" for your browser/file manager on the device.
3. Install [MOTO-HUB Core](https://github.com/vincenzobpt/MOTO-HUB/releases) first if you haven't already.
4. Install the Pro APK.
